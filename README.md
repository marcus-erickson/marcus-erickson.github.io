# AI Builds

A one-page index of my public Claude skills and Chrome extensions. Each card links to the project's page, its download where there is one, and its repository.

## Add a project

1. Open `projects.json` and add an entry to a group, or add a new group.
2. Run `python3 build.py` to rebuild `index.html`.
3. Commit and push. GitHub Pages serves `index.html`.

Each entry has `name`, `repo` (the repository name under marcus-erickson), `description` and `tags`. `page` and `download` are optional, and a card shows a button only for the ones it has.
